How Are the Bullet Results Calculated?

We derive a verifiable random chamber from your seeds using HMAC_SHA256:
hash = HMAC_SHA256(clientSeed:nonce, serverSeed). From this 64-hex hash we extract a fair number with slideWindowNumber (same as other games), then map it to a chamber in [1..6].

Each round starts at round = 0 and increases by 1 after each shot. Let spinChamber be the start chamber (1..6). The chamber used by the current shot is:
result = (spinChamber + round) % 6 (this is 0..5). A hit occurs iff 1 ≤ result ≤ bullets. If hit, we return spinChamber; otherwise -1. 

/** H = HMAC_SHA256(clientSeed:nonce, serverSeed) → hex */
hmacSHA256(serverSeed, clientSeed, nonce) {
  return CryptoJS.HmacSHA256(`${clientSeed}:${nonce}`, serverSeed)
    .toString(CryptoJS.enc.Hex);
},

/** spinChamber ∈ [1..6], uses the same slideWindowNumber as other games */
getSpinChamber(serverSeed, clientSeed, nonce) {
  const hash = this.hmacSHA256(serverSeed, clientSeed, nonce);
  return Math.floor(slideWindowNumber(hash, 6)) + 1;
},

/**
 * Backend-equivalent round result.
 * round starts at 0; bullets typically 1..3 (algorithm allows 1..6).
 * Returns spinChamber on hit, otherwise -1.
 */
getRoundResult(serverSeed, clientSeed, nonce, round, bullets) {
  const spinChamber = this.getSpinChamber(serverSeed, clientSeed, nonce); // 1..6
  const result = (spinChamber + round) % 6; // 0..5
  const hit = (result >= 1 && result <= bullets);
  return hit ? spinChamber : -1;
},

/** The 6-slot sequence starting from spinChamber, e.g. [2,3,4,5,6,1] */
getSequence(spinChamber) {
  const seq = [];
  for (let i = 0; i < 6; i++) {
    seq.push(((spinChamber - 1 + i) % 6) + 1);
  }
  return seq;
},

/**
 * Equivalent to backend getCards(spinChamber, bullets):
 * returns which shot numbers (1..6) will hit.
 */
getCards(spinChamber, bullets) {
  const out = [];
  if (spinChamber <= 0 || bullets <= 0) return out;

  // bullets are labeled 1..bullets
  const bulletSet = new Set();
  for (let i = 1; i <= bullets; i++) bulletSet.add(i);

  let chamber = spinChamber; // current chamber label (1..6)
  for (let i = 0; i < 6; i++) {
    if (bulletSet.has(chamber)) out.push(i + 1); // shot index is 1-based
    chamber = (chamber % 6) + 1; // wrap 1..6
  }
  return out;
}

Notes:
• round is 0-based (0,1,2,...). After each shot, increase by 1.
• The function slideWindowNumber(hash, n) is the same unbiased extractor used in your other games.
• Verification steps: compute the HMAC, derive spinChamber, then apply the formulas above.
